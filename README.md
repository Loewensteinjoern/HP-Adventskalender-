# Die Reise zum Winterphönix

Ein Adventskalender-Spiel im verschneiten Zauberschloss Løvestein. Vom 1. bis 24. Dezember öffnet jeden Tag ein neues Türchen.

**Spielen:** Link in Safari öffnen → Teilen → „Zum Home-Bildschirm“. Danach wie eine App starten (quer halten).

**Testmodus:** `?testtag=N` (0–24) hinter den Link hängen. Eigener Speicherplatz, der echte Spielstand bleibt unberührt.

## Für Entwicklung
- `src/` Programmcode, `data/` Inhalte (JSON), `plan/` Planung, `docs/` gebaute Seite (GitHub Pages).
- `npm run check` = bauen + Tests + Rauchtest (Node, keine Pakete nötig; Rauchtest braucht Playwright).
